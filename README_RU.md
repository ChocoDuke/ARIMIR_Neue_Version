# ARIMIR — новая версия MVP

## Что внутри
- `index.html` — структура экранов.
- `style.css` — адаптивный дизайн.
- `script.js` — переходы, урок «Мой день», гирлянда дня рождения и сохранение прогресса.
- `assets/audio/` — сюда нужно положить готовые MP3 с точными именами из `AUDIO_FILES_RU.md`.

## Запуск
1. Распакуйте архив.
2. Откройте папку в IntelliJ IDEA.
3. Откройте `index.html` в браузере (лучше через встроенный preview или локальный сервер).
4. Для звука нажмите на кнопку в приложении. Если браузер не находит MP3, приложение покажет имя отсутствующего файла. Синтезированный голос браузера намеренно не используется.

## Важно
В этот архив не были приложены сами MP3-файлы ElevenLabs, поэтому в `assets/audio/` оставлен файл-инструкция. Код ссылается на точные имена аудио, а не подменяет озвучку голосом браузера. Когда MP3 будут добавлены, положите их прямо в `assets/audio/`.

## Режимы даты
В `script.js` есть `demoMode = true`. Для демонстрации использован фиксированный сценарий хакатона: 24 октября 2026 года, 74 сна до 6 января. Чтобы включить реальную дату устройства, измените на `demoMode = false`. Прогресс demo-режима и реального режима хранится отдельно в браузере.

## Область MVP
Только два раздела: «Мой день» и «Мой день рождения». Старые функции коллекции персонажей, чата, музыки и календарных экранов не используются.
